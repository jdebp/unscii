======================== MATHEMATICAL ALPHABETS =============================

Strictly speaking, we are including code points here that are not in Unicode.
Unicode had the problem that it had already included several odd mathematical letters here and there in plane 0 by the time that people got around to adding this to plane 1.

It is not worth worrying about the scenario where someone prints an unassigned code point and is surprised that it renders as the glyph for the letter that it blatantly would be.

This is far from complete; more work to find home computer/arcade fonts with enough "mathsiness" is needed.

We don't bother with 8x8 or 8x16; there is not enough wiggle room in those for 14 different glyph variants of each single letter.
